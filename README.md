# 短剧库

独立重构版，支持黄果、黄豆、红果的在线点播、追剧与下载管理，适用于 macOS、Windows 和 Linux。Go 标准库后端、原生 JavaScript 与 CSS，无 npm、框架或 CDN 运行依赖。首次打开默认展示红果，以后记住当前浏览器的筛选。

本轮开发在新“短剧库”目录进行，原 `juku` 和“果果剧库”不回写。功能范围与验证记录见 [重构说明](docs/refactor-progress.md)，后续计划见 [迭代清单](docs/iteration-roadmap.md)。

请仅观看或下载你拥有权利或已获授权的内容。在线播放、下载和合并需要本机 FFmpeg，详见 [FFmpeg 说明](bin/README.md)。

## 项目结构

```text
.
├── internal/
│   ├── app/              下载、点播、站源、剧库、配置和 HTTP 接口
│   └── webui/            原生 HTML、播放器脚本、样式及 Go 内嵌资源
├── scripts/              跨平台构建、启动脚本
├── docs/                 使用指南与 Render 说明
├── bin/                  可选的便携 FFmpeg
├── Dockerfile            容器镜像（Go + FFmpeg）
├── docker-compose.yml    本机 Docker 启动
├── render.yaml           Render Blueprint
├── main.go               应用入口
├── go.mod
└── README.md
```

`internal/app` 按职责组织文件：`config_*` 管理配置，`provider_*` 对接站源，`library*` 管理剧库，`download*` 处理下载，`network_*` 处理网络，`ui_*` 提供管理接口，`desktop_picker*` 调用系统目录选择器。平台专属实现保留 Go 的文件名后缀约定。

页面骨架位于 `internal/webui/index.html`。`main.js` 连接导航、剧库、追剧、详情、下载与设置模块，播放器、历史、排序和榜单保持独立组件；`app.css` 管理共同样式和明暗主题。全部资源通过 `go:embed` 编译进程序。修改后重新构建即可，不需要额外的前端构建步骤。业务实现留在内部包中，命令入口不承载业务逻辑。

## 源码运行

需要 Go 1.21+。以下命令均在项目根目录执行：

```bash
go run .
```

默认监听 `0.0.0.0:8998`，本机自动打开 `http://127.0.0.1:8998`；同一局域网内的设备使用 `http://运行程序电脑的局域网IP:8998` 访问，并允许防火墙放行 TCP 8998 端口。`0.0.0.0` 是监听地址，不是其他设备的访问地址。

不自动打开浏览器时使用 `go run . -open=false`；仅限本机访问时使用 `go run . -listen 127.0.0.1:8998`。本地管理界面没有身份验证，请仅在可信局域网使用。公网部署必须设置 HTTP Basic Auth（`JUKU_BASIC_AUTH_USER` / `JUKU_BASIC_AUTH_PASS`），不要把未登录的界面暴露到公网。全部参数见 `go run . -help`。

## 构建

macOS / Linux 构建四个平台版本：

```bash
./scripts/build.sh
```

Windows 在项目根目录执行 `scripts\build.bat`，构建 Windows x64 版本。构建产物统一放在 `dist/`，也可使用 `scripts/` 中对应系统的启动器。

分发时只需对应平台的可执行文件，页面已经内嵌，无需附带源码或配置。更多平台与参数见 [使用指南](docs/usage.md)。

## Docker

需要本机已安装 Docker。镜像是 Linux 版程序 + 系统 FFmpeg，剧库缓存和下载目录用数据卷保存，不打进镜像。

```bash
docker compose up --build
```

本机默认映射 `127.0.0.1:8999`。局域网再改成 `8999:8999`；公网请走反代并设置 Basic Auth。

## 找剧、追剧与下载

- **剧库**：顶部直接显示搜索、筛选、排序、榜单和批量选择；3:4 大海报一键播放，剧名打开详情，卡片可直接收藏或下载。批量选择范围在当前页面显示。
- **追剧**：分为“在看 / 想看 / 已看”，支持收藏、撤销与手动已看。首屏仅在有记录时显示“接着上次看”。收藏独立持久化，真实进度沿用原播放记录。
- **下载**：独立页面直接显示保存目录，一步更改目录；保留合集与分集操作，批量管理和低频操作收进菜单。桌面剧库可打开下载概览侧栏。
- **手机与桌面**：手机底部三入口，桌面顶部导航；桌面“代理 / 设置”保持可见。详情在桌面为侧栏，在手机为底部面板，浏览器返回先关闭当前弹窗。
- **外观**：暖白与墨绿、统一线性图标和紧凑控件；支持浅色、深色和跟随系统，筛选及主题保存在当前浏览器。布局数据与验证见 [紧凑海报布局](docs/ui-refinement.md)。

新集提示只根据剧库已确认的集数变化显示。不会因为打开追剧页面自动抓取全库或补齐旧数据；历史资料仍通过“更新剧库”触发。详见 [追剧清单](docs/following.md)。

## 红果 App 剧库

红果改用 App 分类目录作为主要入口，支持真人剧、漫剧、AI 剧；保留网页回退，不再将原有 1514 部缓存当作资源上限。黄果、黄豆的站源和功能保持不变。

- **缓存优先**：打开页面不自动重新爬取；首次加载或手动更新时逐页展示。
- **统一更新**：“更新剧库”检查当前站源的新内容、继续读取未完成的红果 App 分类，并在后台分批补充历史资料；分页进度保存在原有缓存中。
- **合并而非覆盖**：所有站源按剧 ID 合并，保留未在本批返回的旧条目，避免刷新结束后数量突然回落。
- **联网搜索**：选择红果或全部站源后，点击按钮或按回车可补充红果搜索结果；输入时仍只做本地筛选。
- **本地签名与完整分集**：不需要 Python、模拟器或外部签名服务，继续支持在线点播和下载。

- **兼容 App 封面**：签名 HEIC 封面由本机自动转换为 JPEG，兼容内置 FFmpeg，重复请求使用限额内存缓存。

已有缓存升级后请手动点击“更新剧库”。实现、实测样本和已知限制见 [红果 App 接入说明](docs/hongguo-app.md)。

## 排序与站点榜单

剧库工具栏直接提供最新上线、最早上线、热度、播放量和名称排序，记住上次排序选择。本地筛选和联网搜索结果都参与排序；名称中的“第二季、第三季……第十季”按数字顺序比较。缺失字段置后，全部缺失时明确提示并保留原顺序，热度与播放量分别比较。

Web UI 首次取得新条目时保留当前接口提供的全部排序字段；需要其他接口的数据在后台补充，列表、搜索和榜单先返回。历史条目通过“更新剧库”按当前站源分批异步补齐，每次最多 40 部，优先当前筛选结果；选择红果或全部站源时也继续读取红果目录。后台补充完成后自动更新排序和缓存，前台请求优先；源站确实没有提供的值保留未知，不猜测日期或把播放量当热度。

点击剧库标题旁的“榜单”，在紧凑弹窗内切换站源和榜单类型，可分页浏览、直接播放或下载。已接入三站 12 种真实榜单：红果总热播、真人剧、漫剧、AI 剧榜；黄豆总榜、魔改、搜索、收藏、完结榜；黄果热播、推荐、潜力榜。保留站点名次，不将本地排序包装为榜单；目前接口未提供日、周、月周期榜。

榜单使用文字列表，不读取榜单图片。站点更新时间与获取时间分别标注，短时间内复用数据；刷新失败时保留上次结果并明确提示。更多说明见 [使用指南](docs/usage.md#排序与站点榜单) 和 [榜单接口说明](docs/rankings.md)。

## 在线点播

点击剧库海报上的“播放 / 续播”打开独立播放器，选集每页 30 集并支持输入跳转，支持进度跳转、倍速、暂停和自动下一集，不加入下载任务、不保存视频文件。下载合集及展开的分集也有“播放”按钮：优先播放本地已完成文件，播到未完成分集时仅自动下载该集，不重复创建任务。点播使用 FFmpeg 实时转换为浏览器兼容格式，需要包含 `libx264` 和 AAC 编码器的完整版本。

“追剧 → 历史记录”或“更多 → 历史记录”打开完整观看记录，支持搜索、删除和清空。播放后自动保存分集与时间位置，剧库、搜索结果和下载合集可直接“继续观看”；程序重启后仍保留，预缓存不计入观看。详见 [观看记录说明](docs/playback-history.md)。

播放设置中提供默认开启的“预缓存下一集”：当前集缓冲完成、临近结束时提前准备下一集，切集直接复用缓存。开关会记忆，只保留一个待播分集，关闭窗口即释放，不新增下载任务。详见 [预缓存说明](docs/playback-prefetch.md)。

红果播放已接入真实文字弹幕：播放设置中提供记忆开关，随播放进度分段异步加载，支持暂停、倍速、跳转和全屏。滚动使用浏览器原生线性动画；弹幕失败不影响播放。普通评论暂未接入，详见 [弹幕说明](docs/playback-danmaku.md)。

未找到 FFmpeg 时自动下载并校验对应平台的便携版本，无需用户手动安装。进度与失败重试入口在界面内显示；已有 FFmpeg 保持不变，详见 [FFmpeg 说明](bin/README.md)。

## 运行数据

- `data/`：首次运行自动生成配置、剧库缓存和任务状态，观看后保存播放记录，收藏后保存 `following.json`，无需事先准备配置文件。
- `data/logs/app.log`：自动保存播放、媒体续读、下载和资料补齐等诊断事件，单文件最多 5 MiB，另保留两份轮转日志。位置、字段和故障处理见 [故障排查](docs/troubleshooting.md)。
- `短剧下载/`：默认视频目录；支持在界面中调用系统文件夹选择器，也可使用 `-out` 指定其他目录。
- `dist/`：构建产物，不参与源码分发。

独立程序以所在目录为工作目录；源码运行和项目内 `dist/` 程序使用项目根目录。目录调整不改变原有配置格式、缓存、任务和下载路径规则。自定义路径、代理、站源与任务操作详见 [使用指南](docs/usage.md)。

## 独立运行

当前阶段只维护本目录，遵循 [AGENTS.md](AGENTS.md)。默认端口为 **8998**，便于与原版 8999 并行运行。运行数据由本目录首次启动时生成；本次交付不复制旧项目的配置、缓存、任务、视频或 FFmpeg，也不自动同步到旧目录。
